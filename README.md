Overview
The Ultimate VPS Booster Script is designed to help optimize the performance and speed of your Debian and Ubuntu servers. With simple, automated steps, this script provides multiple levels of optimization, from basic improvements to advanced, all-in-one performance boosting techniques.

Key Features:
Fully compatible with Debian and Ubuntu systems.

Offers multiple optimization levels: Basic, Intermediate, Advanced, and Ultra Boost.

Includes network, CPU, disk I/O, and swap optimizations.

Safe, user-friendly process with clear prompts.

Easy to use and execute, with a simple selection menu.

Installation
Prerequisites:
This script requires root (administrator) privileges to execute.

The script is compatible with Debian and Ubuntu operating systems.


## Optimization Levels:

**Basic Boost:**

*Installs essential performance tools (e.g., haveged, ufw, preload).*

**Creates a 50GB swap file.**

*Performs basic tuning like TCP syncookies and enabling IP forwarding.*

**Intermediate Boost:**

*Builds on Basic Boost by enabling BBR (TCP congestion control).*

## Optimizes system buffers for better network performance.**

**Advanced Boost:**

**Includes Intermediate Boost optimizations.**

*Adds CPU and disk I/O optimizations (e.g., irqbalance, tuned profiles).*

*Configures file descriptor limits to improve server performance under load.*

 **Ultra Boost (All-in-One):**

*Includes all optimizations from previous levels.*

*Applies advanced TCP tuning and additional network tweaks.*

*Configures firewall rules (UFW) and performs system cleanup.*

*After selecting your preferred optimization level, the script will apply the changes and recommend a reboot for full effect.*

## **Important Notes**

***Root Access Required: The script must be executed with root privileges. If you're not running as root, you'll receive an error message prompting you to use sudo.***

***Reboot After Completion: While optimizations will take effect immediately, a system reboot is recommended for full impact.***

***Backup Your Data: As with any system optimization, it's always a good idea to back up important data before making major changes.**



# Ultimate VPS Booster Script

**Installation
Prerequisites:
This script requires root (administrator) privileges to execute.**

## The script is compatible with Debian and Ubuntu operating systems.

**Steps to Install:
Clone the Repository:**

```git clone https://github.com/IC-DEVLEPMENTS/Ultimate-VPS-Booster-Script-Debian-Ubuntu-.git```

## Make the Script Executable:

```chmod +x ULTIMATE-VPS-BOOSTER.sh```
## Run the Script: To run the script, execute it as root:

```sudo ./ULTIMATE-VPS-BOOSTER.sh```
