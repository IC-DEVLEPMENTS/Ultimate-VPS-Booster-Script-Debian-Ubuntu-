# Ultimate VPS Booster Script

**Installation
Prerequisites:
This script requires root (administrator) privileges to execute.**

## The script is compatible with Debian and Ubuntu operating systems.

**Steps to Install:
Clone the Repository:**

```git clone https://github.com//ultimate-vps-booster.git```

```cd ultimate-vps-booster```

## Make the Script Executable:

```chmod +x vps_booster.sh```
## Run the Script: To run the script, execute it as root:

```sudo ./vps_booster.sh```
## Done Now  ✅
